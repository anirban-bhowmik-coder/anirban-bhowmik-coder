# 🧪 How I Build

I usually follow a simple cycle:

<div align="center">

```text
        💡 IDEA
          │
          ▼
      🔍 EXPLORE
          │
          ▼
     🧩 BREAK DOWN
          │
          ▼
       🛠️ BUILD
          │
          ▼
       🧪 TEST
          │
          ▼
       💥 BREAK
          │
          ▼
       📚 LEARN
          │
          ▼
      🔁 REBUILD
          │
          ▼
       🚀 IMPROVE
```

</div>

I don't expect the first version to be perfect.

I build, test, find weaknesses, understand what went wrong, and improve the next version.
