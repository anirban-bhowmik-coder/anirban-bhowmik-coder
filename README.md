> **Multi-agent decision intelligence architecture designed for complex investigations requiring evidence cross-examination, conflict detection, and defensible synthesis.**
- **Status**: **Phase 1 • In Active Development** *(Note: Replaces legacy prototype KIRO)*
- **Architecture**: Specialized multi-agent consensus workflow with strict provenance tracking.
- **Core Triad**:
  - `Orchestrator`: Decomposes macro inquiries into structured investigation graphs.
  - `Researcher`: Queries live data sources and isolates relevant evidentiary excerpts.
  - `Verifier`: Cross-checks extracted claims, identifies contradictions, and tags evidentiary states:
    `[VERIFIED]` • `[CONFLICTING]` • `[UNCERTAIN]` • `[UNSUPPORTED]`

- **Technology Stack**: React, Vite, Python, FastAPI, Pydantic, Gemini Models, Grounded Search
